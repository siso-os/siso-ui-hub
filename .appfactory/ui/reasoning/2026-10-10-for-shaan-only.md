# For Shaan only: no sign-in, no per-user features

## Decision
v1 has one user. No GitHub sign-in, no per-user storage, no hosted dashboards. His data stays on the laptop in git.
A read-only public copy comes later, once he uses it daily.

## His words
> "this shit I build, I don't want to spend tokens building this shit on for other people I want to build up my SISO OS
> for myself, otherwise it's fucking pointless" (idea 23, 10 Oct 2026 04:57)

## Why
Every feature for other people costs tokens he wants spent on his own work, and a public copy built from the same code
later costs nothing extra.

## Instead of
The first spec's GitHub sign-in and "bring your own repo" for other users (spec §2 before 04:57).
