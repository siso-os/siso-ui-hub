# Choose SISO UI by looking

Pages: P-core → P-siso-ui-picks → P-siso-ui

1. From the UI core he opens the pick page: candidates in decisions, each rendered, his old words on each.
2. Take or Skip on each card, with his words if he likes; saved to `factory/siso-ui/picks.jsonl`.
3. What he took becomes SISO UI: one install line per part, listed on the SISO UI page.
