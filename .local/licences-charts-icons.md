# UI chart and icon library licences

Checked 2026-10-14. Budget: about 23 fetches plus about 15 searches. Rows are in `licences-charts-icons.jsonl`.

## Read from the LICENSE file (copy and resale)

- evilcharts: MIT. Copyright 2026 Gurbinder.
- bklit-ui: MIT for packages/ui only. packages/studio is proprietary (LICENSE-STUDIO.md) and cannot be resold.
- airbnb/visx: MIT (Copyright 2017-2018 Harrison Shoff).
- lucide-animated (pqoqubbw/icons): MIT. README says demos and tutorials may not be redistributed or resold (secondary summary, check the README).
- animateicons (Avijit07x): MIT. Copyright 2025 Avijit Dey.
- motion-primitives (ibelick): MIT. Copyright 2024 ibelick.
- magicui: MIT. Copyright Magic UI.
- itshover: Apache-2.0 in the LICENSE file. The README says MIT in one bullet. The LICENSE file governs.

## Read from the repo page only (LICENSE file not read)

- animate-ui (imskyleen): MIT per sidebar and README. The raw LICENSE returned 404 on main and master. Read it before any resale. The Commons Clause wording found in searches belongs to React Bits and Canvas UI.
- Hugeicons: free icons are MIT (copy and resale OK). Pro icons cannot be sold as source or put in paid kits, so copy_ok is false for Pro.

## Not found or unverified

- axicharts: no project found. Name-alikes (ApexCharts, AxiisCharts) are different projects.

- iconiq: no repo found. MIT only per a Product Hunt-style listing (hunted.space).
- animbits: no repo and no licence on animbits.dev. Do not copy until confirmed.
