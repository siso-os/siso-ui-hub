# Package workbench

This example app is a searchable browser and playground for the SISO UI source packages. Its demos render from package imports and original source examples; routes and state belong to this consumer.

The component browser covers 129 free Arc install targets from 126 source families: 54 atom targets across 51 families, 42 composed components, 21 page sections and 12 charts. Arc Pro is excluded. The charts view includes 117 original MIT Evil Charts Recharts presets as a separate collection. Charts load one selected example at a time. The three notification treatments are the Arc notification centre, the MIT Uiable popover and Arc's toast stack; three saved 21st.dev examples are author links pending redistribution rights.

The widget playground explains how content fits inside a widget frame, how the board arranges widgets, and how data states and layout export work. Its records are illustrative fixtures. The site views separate the accepted full footer and its component parts from the product glyphs and 447-asset library; asset source and hash data travel with the manifest.

`packages/siso-ui` (`@siso/ui`) is the UI Hub umbrella, intended for `sisodias/siso/packages/ui`; that destination does not exist yet. The eight focused package shards remain separate build inputs. The private 0.3 release records nine package declaration checks, 1,085 source checks, 1,224 installed-file matches and compilation of the source examples. The asset set contains 447 original files with 429 small raster previews. Browser and publication receipts describe the exact observed scope separately. See [`PACKAGES.md`](../../PACKAGES.md) for package boundaries, consumer responsibilities and build commands.
