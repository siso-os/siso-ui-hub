# halo-inspiration Side Nav

**Source:** `halo/inspiration/isso-dashboard/src/shared/layout/isso-sidebar/`
**Commit:** `2ec675d`
**Framework:** React + TypeScript, Lucide icons
**Dependencies:** react-router, custom hooks (useLayout, navigation context)

## What it does
- Dashboard sidebar shell for the ISSO (customer dashboard) application
- Navigation groups with collapsible sections
- Dashboard context switching
- Responsive sidebar that adapts to screen size
- Logo/branding at top
- Navigation item icons and labels
- Footer/account section support

## Distinctive features
- **IssoSidebarShell** — specialized shell for dashboard layout
- **ISSO-branded** — customer-facing dashboard navigation, not admin/internal tool
- **Responsive design** — adapts layout for different screen sizes
- **Context-aware** — integrates with ISSO application context
