# Faces Lab research source

Five pinned SISO-only candidate files are preserved beside the existing agent package. They are not exported, packaged, installed or substituted for its current face design. The two SVGs contain SISO Agency and Agent Base marks; HALO marks and mixed galleries remain outside this selection. Exact source and adapted destination hashes are in source-receipt.json.

The original React adapter referenced window.AgentSoul, but the selected engine defines window.FaceMochi. This local adapter uses FaceMochi; its sibling JS/CSS imports and public props remain intact. Both files stay research candidates. React mounting and visual acceptance are unverified.

Run `node check.mjs` here for the six statuses, deterministic hue, reduced-motion scheduling, 24/32/48 size metadata and teardown using a synthetic DOM. The check does not prove layout, animation appearance or browser compatibility. Source verification also parses the SVGs and rejects script/external resource references. No live app, remote fetch or private data is needed.

No changes to package exports, published files, component inventory or production assets are part of this preservation. Shaan's artistic acceptance is not established by the historical source review.
